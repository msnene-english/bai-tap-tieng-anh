Unit 2  ·  Unless = If … not

45 câu · Dạng 1: IF ➜ UNLESS (15)  +  Dạng 2: UNLESS ➜ IF (15)  +  Dạng 3: Trắc nghiệm (15) · chấm điểm thông minh

⭐ Điểm: 0/0

📚 A. TÓM TẮT LÝ THUYẾT & MẸO CẦN NHỚ

Nghĩa: If = Nếu  ·  Unless = If … not = Nếu … KHÔNG làm gì
🟢 Dạng 1 — Mệnh đề IF đang PHỦ ĐỊNH (don’t / doesn’t)
Bỏ don’t / doesn’t, thay If bằng Unless. Mệnh đề chính GIỮ NGUYÊN. (Bỏ doesn’t thì nhớ thêm -s cho động từ.)
If you don’t study, you will fail. ➜ Unless you study, you will fail.
🟠 Dạng 2 — Mệnh đề IF đang KHẲNG ĐỊNH
Thay If bằng Unless, rồi ĐẢO mệnh đề chính: will ⇄ won’t.
If you sleep early, you will be healthy. ➜ Unless you sleep early, you won’t be healthy.
🔵 Dạng 3 — Đổi từ UNLESS sang IF
Thay Unless bằng If, thêm don’t / doesn’t (động từ về nguyên thể) hoặc isn’t / aren’t nếu là động từ TO BE. Mệnh đề chính GIỮ NGUYÊN.
Unless it rains, we will play soccer. ➜ If it doesn’t rain, we will play soccer.
⚠️ Mẹo vàng: Unless đã mang nghĩa phủ định rồi — sau Unless KHÔNG BAO GIỜ có don’t / doesn’t!
